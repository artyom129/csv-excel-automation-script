# Upwork Portfolio Entry

## Title

CSV / Excel Data Cleaning Automation

## Description

Built a Python automation script that cleans messy CSV order data, removes duplicate records, validates names, emails, dates, quantities, and prices, and generates a structured Excel report.

The workbook includes a dashboard, clean-data sheet, invalid-records sheet, calculated revenue metrics, and a chart for quick review.

## Technologies

Python, Pandas, OpenPyXL, CSV processing, Excel automation, data validation.

## Client value

The automation reduces repetitive spreadsheet cleanup, improves data quality, and produces an accounting- or CRM-ready report.
